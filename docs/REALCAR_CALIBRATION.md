# 실차 캘리브레이션 및 토크벡터링 이관표

이 문서는 `dev` 브랜치를 실차에서 단계적으로 검증할 때 어떤
숫자를 고정하고, 어떤 숫자를 시험 중 바꿔야 하는지 정리한 단일 기준이다.

## 코드에서 값을 바꾸는 위치

- 차량·센서·구동계 값: `src/modules/realcar_calibration.h`
- TV 정책과 PID: `src/modules/tv/tv_config.h`
- 센서 핀: `src/core/board_pins.h`
- ADC 중심값·차량 보정값: `src/modules/realcar_calibration.h`

알고리즘 `.cpp`에 차량 숫자를 직접 추가하지 않는다. 실측값을 갱신한 뒤에는
`pio test -e native`와 `pio run -e esp32dev`를 모두 통과시킨다.

## 현재 파라미터 상태

### 현재 2모터 bring-up 설정

- `BRAKE_SENSOR_INSTALLED = false`: 미장착 GPIO33을 읽지 않고 브레이크/회생 입력을 0으로 고정
- `REQUIRE_BOTH_MOTOR_CONTROLLERS = true`: 좌·우 컨트롤러가 모두 핸드셰이크되어야 시험 허용
- 핸드셰이크 전에는 해당 컨트롤러 ID로 일반 토크 프레임을 보내지 않음
- `0xAA` 응답 전송이 `ESP_OK`일 때만 해당 컨트롤러를 연결 완료로 표시
- 시리얼 모니터 115200 bps에서 좌/우 핸드셰이크 성공·실패를 확인
- PID `Kp/Ki/Kd = 0`: 센서 장착 전까지 TV 차등제어 OFF, 연결된 모터에는 50:50 분배값만 전달
- 정상 구동 명령은 목표속도 `+4000 rpm`, RUNNING bit `1`; 회생 명령은 목표속도
  `0 rpm`, RUNNING bit `1`로 송신한다. 정지 명령만 RUNNING bit를 `0`으로 만든다.
- 핸드셰이크 후에도 스로틀이 1% 이하로 약 300 ms 유지되어야 Drive로 arm된다.
- 디버그 출력의 `ARM/HS/DM`은 각각 토크 허용, 컨트롤러 핸드셰이크,
  200 ms 제어루프 deadman 상태다. 세 값이 모두 1이어야 전류 명령이 전달된다.

이 프로파일은 물리 브레이크, 비상정지, 전원 차단이 확보된 정비·저속 시험용이다.
두 번째 모터와 브레이크 센서 장착 후 위 두 플래그를 모두 `true`로 되돌리고
브레이크 active level을 실측한다.

### 스로틀 캘리브레이션 — 구동 전 필수

현재 `THROTTLE_RAW_MIN=620`, `THROTTLE_RAW_MAX=3720`은 배선 확인용 초기값이며
실측 확정값이 아니다. 바퀴를 띄운 상태에서 시리얼의 `thrRaw`를 읽어 다음 순서로
교체한다.

1. 페달을 완전히 놓고 10초간 최솟값과 최댓값을 기록한다.
2. 페달을 끝까지 밟고 10초간 최솟값과 최댓값을 기록한다.
3. released 노이즈 최댓값보다 약간 큰 값을 `THROTTLE_RAW_MIN`으로, full 구간의
   안정적인 최솟값보다 약간 작은 값을 `THROTTLE_RAW_MAX`로 둔다.
4. 전원 재인가 후 페달을 놓았을 때 `thr=0.0`, `ARM=1`인지 확인한다.
5. 페달을 아주 천천히 밟아 `thr`가 단조 증가하는지 확인한다. 반대로 움직이거나
   놓은 상태에서 0%가 아니면 지상 구동하지 않는다.

현재 Normal 모드 총 구동 한도는 30 A이며 TV OFF의 50:50 분배로 좌·우 모터에
각각 최대 15 A가 전달된다. 이는 최초 저속 bring-up 값이다. 한쪽 컨트롤러의
핸드셰이크가 빠지면 `HS=0`, `ARM=0`을 유지하며 어느 모터에도 구동 전류를
허용하지 않는다.

## WSS 48 PPR와 구름반경

현재 WSS는 림 안쪽 자석을 세어 휠 회전수를 구한다. 자석 장착반경은
차속 계산에 사용하지 않는다. 림·휠·타이어가 한 몸으로 회전하므로 자석 링
한 바퀴가 곧 휠 한 바퀴다.

```text
wheel_rpm = pulse_delta * 60000 / (48 * dt_ms)
vehicle_speed = wheel_rpm * 2*pi*rolling_radius / 60
```

PCNT 드라이버는 상승엣지만 세므로 PPR는 자석 수와 자동으로 같다고 가정하지
말고, 조립 후 각 바퀴를 정확히 한 바퀴 돌려 상승엣지가 48개인지 확인한다.

48 PPR를 10 ms마다 바로 RPM으로 바꾸면 한 펄스 차이가 125 rpm이다. 이
계단값이 차속 유효성 검사와 슬립 판단을 흔들지 않도록 실차 경로는
`wheel_speed_compute_filtered()`를 사용한다. `WSS_FILTER_TIME_CONSTANT_S`를
줄이면 반응은 빨라지고 노이즈는 커지며, 늘리면 반응은 느려지고 값은 안정된다.

### 유효 구름반경 실측

1. 운전자 탑승, 실제 주행 공기압과 타이어 온도를 기록한다.
2. 직선에서 20~50 m를 천천히 이동하며 네 채널의 누적 펄스를 기록한다.
3. 바퀴별로 아래 식을 계산한다.

```text
rolling_radius_m = distance_m * PPR / (2*pi*accumulated_pulses)
```

전륜 두 값의 평균을 `WHEEL_SPEED_ROLLING_RADIUS_M`의 첫 보정값으로 쓴다.
좌우 차이가 크면 반경을 억지로 평균내지 말고 공기압, 자석 누락, 펄스 노이즈를
먼저 조사한다.

## CarMaker 값과 실차 값의 관계

CarMaker `BOM197` 제어기는 질량 197.345 kg, 축거 1.53 m, 후륜 윤거
1.09 m, CG 높이 약 0.2801 m, 후륜 정적 하중비 약 0.6181을 사용한다.
이 브랜치는 실차 시험의 시작점을 맞추기 위해 같은 초기 형상값을 사용한다.

CarMaker 타이어 반경 0.22606 m와 감속비 3.73은 시뮬레이션 플랜트 프로파일
값이다. 실차 코드는 초기 구름반경 0.2387 m와 실제 구동계 감속비 3.72를
유지한다. 숫자가 다른 것은 의도적이며 실차 측정값이 확보되면 측정값을 우선한다.

## 실차 시험 순서와 변경 허용 범위

### 하네스 v5 / `origin/GPIO-fixed` 반영값

- 단일 핀 기준은 `src/core/board_pins.h`다.
- CAN RX/TX = D16/D17, throttle ADC = D32, brake digital = D33, gear ADC = D27
- WSS FL/FR/RL/RR = D36/D39/D34/D35
- steering ADC = D25, IMU RX/TX = D22/D21
- 브레이크는 PCB의 12 V→3.3 V 디지털 변환 뒤 HIGH를 raw 4095로 매핑한다.
- 하네스 v5에 shutdown/start 전용 VCU GPIO가 없으므로 safety wrapper도
  `GPIO-fixed`와 동일하게 hard-wire/Cluster 경로를 전제로 한다.

### 1. 정지/잭업 — PID 0 유지

- 물리 비상정지와 LV/HV 전원 차단이 실제로 토크를 끊는지 먼저 확인
- 스로틀 `thrRaw`/0%/100% 실측 캘리브레이션 후 재빌드
- CAN 핸드셰이크 로그와 `ARM=1 HS=1 DM=1` 확인
- 좌·우 컨트롤러가 각각 `L`, `R` 핸드셰이크 성공 로그를 남기는지 확인
- CAN analyzer에서 구동 프레임 Byte2~3=`36000`(4000 rpm offset), Byte4=`0x01` 확인
- 네 WSS 채널 위치와 PPR 48 확인
- 전진 회전에서 모든 RPM이 양수인지 확인
- IMU yaw/ax/ay 영점과 부호 확인
- 조향 직진 중심, 좌/우 최대, invert 확인
- `torque_L == torque_R == total_current/2` 확인

### 2. 직선 저속 — PID 0 유지

- 누적 펄스와 실거리로 구름반경 보정
- 전륜 평균 차속과 GPS/거리 기준 차속 비교
- 48 PPR/100 Hz 양자화와 `vehicle_speed_valid` dropout 확인
- 0.165 m 값이나 센서 장착반경을 차속 반경으로 다시 넣지 않음

### 3. 정상원선회 — PID 0 유지

- 조향 Unit과 실제 평균 전륜 조향각 매핑
- 목표 yaw와 실측 yaw의 부호 및 정상상태 오차 기록
- CG/하중배분/LLTD는 로그 없이 임의 튜닝하지 않음

### 4. TV 저권한 시작

- 별도 enable이 생기기 전까지 `kp=ki=kd=0`이 master OFF다.
- 최초 시험은 작은 P 게인과 편도 차등전류 ±0.5 A 수준부터 시작한다.
- 한 번에 게인과 Mz 상한과 μ를 함께 바꾸지 않는다.
- 각 시험마다 파라미터, 펌웨어 커밋, 타이어 압력, 운전자 질량, 로그를 남긴다.

### 5. 슬라럼 확장

- 차속을 고정하고 OFF/ON을 반복한다.
- yaw RMS뿐 아니라 beta 추정, 후륜 슬립 추정, 좌우 전류, 포화시간을 함께 본다.
- CarMaker에서 사용한 Kp=35, Ki=3, Mz=100 N·m를 실차에 한 번에 복사하지 않는다.
